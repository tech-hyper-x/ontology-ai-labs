# 부품 식별

1. find_part 로 후보를 찾는다. 한국어 이름(서보 · 모터 · 휠)은 원천 별칭(servo · motor · wheel)으로 바꿔 찾는다.
2. 후보가 하나면 확정한다. 같은 별칭의 과거 부품이 있으면 현재 BOM 부품을 고르고 그 사실을 밝힌다.
3. 후보가 둘 이상이고 구분할 근거가 없으면 확정하지 않고 후보 목록으로 되묻는다.
   예: "servo" 와 "servoblock" 은 이름이 비슷하지만 다른 부품이다.
4. 후보가 없으면 "미등록"으로 답하고 품번을 요청한다. 비슷한 부품을 임의로 고르지 않는다.
