# 새로운 업무 질문 한 개 설계하기 · 작성 예시

G01의 50대 조건을 20대로 바꾼 사례입니다. 결과는 제공 BOM 기준의 기대값입니다.

| 항목 | 작성 예시 |
|---|---|
| 질문과 업무 담당자 | 생산 담당자가 묻습니다. 로버 20대를 만들려면 서보 2000-0025-0002가 총 몇 개 필요한가요? |
| 바꾼 조건과 그대로 둔 조건 | 생산 대수만 50에서 20으로 변경. 부품·최신 판 `6b2c5a9`·낱개 단위 유지. |
| 필요한 원본 파일·행·시점 | `parts_list/parts_list.csv@6b2c5a9#row10`에서 `rocker bogie`의 원천 수량 2와 배수 2 확인. |
| CQ와 유형 | CQ-02 · 수량 |
| 필요한 개체·관계와 이유 | Product·Assembly·BOMLine·Part·Revision을 연결해 같은 개정판에서 부품 사용처와 배수를 찾습니다. |
| 표 조회 또는 경로 추적 | 기준 행에서 2개 × 조립품 2개 × 20대 = 80개를 독립 검산합니다. 그래프 답변에서도 같은 판 경로와 원천 행, 낱개 단위를 확인합니다. |
