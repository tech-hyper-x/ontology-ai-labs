# Ch8 강사용 진행 메모

20분 계획: 도입·독립 참조·문항 분포 3 → 지표·방식·채점 기준 4 → 채점 예측·역사적 오류·원인·검사 한계 5 → 응답 작업본 수정 2 → 대표 3문항 실제 실행·재채점·다음 파트 연결 6.

사전 설치와 전체 135회 실행은 별도입니다. 시간은 300자/분 낭독과 조작·기록 활동을 합친 계획이며 리허설 실측 전입니다.

- ch08_reference는 45문항의 참조 일치를 확인하며 기준 파일을 덮어쓰지 않습니다.
- 교육용 8응답, 역사적 평가 기록, 실제 새 실행을 분리합니다. 과거 responses.jsonl이 없는 상태를 숨기지 않습니다.
- G43 역사적 실패는 미검색, 구성 사례의 doc_not_cited는 검색 후 인용 누락입니다.
- 자동 통과 두 사례를 업무적 정답으로 인정하지 않습니다. 채점기를 몰래 수정하지 않습니다.
- G30 작업본 수정은 답변 한 건의 편집입니다. 에이전트 개선을 확인하려면 코드 수정·새 실행·회귀 검사가 필요합니다.
- 전체 정확도보다 도구/답변/보류의 차이와 오류 근거에 시간을 씁니다. 기존 41/45 등을 새 측정으로 제시하지 않습니다.
- 서보 공식 사진·Lucide 아이콘을 재사용하고 문항 수 막대를 정확도 그래프로 설명하지 않습니다.
- G01·G16·G30의 새 실행은 본 실습입니다. 고정 모드와 실제 모델 평가는 구분하고 전체 135회만 선택으로 둡니다.
- 검수에서 재현한 G01 오분류를 도구 검사 passed / Golden wrong_value의 차이로 설명합니다. 현재 수강생 출력과 대조하며 같은 코드 재실행은 재현 확인으로 기록합니다.
