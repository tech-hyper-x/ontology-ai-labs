## 시연 구분

ch06_calculate는 CSV 독립 검산, ch06_purchase는 작은 교육용 작성과제. Neo4j·LLM 없이 실행. ch06_mcp는 실제 FastMCP Client 호출이며 업무도구는 적재된 Neo4j 필요. canned 화면·CSV 결과를 HTTP 성공 증거로 설명하지 않는다. MCP 서버 재시작 시 기존 포트 점유부터 확인.

## 수강생 작성

구매 과제의 calculate 함수만 수정. 기대값과 검사기는 유지. 작성 후 --check의 3개 조건 통과 확인. 다음 과제는 tool-request.json의 units만 바꾸고 MCP 결과를 비교한다. 교체 판단·에이전트 작성은 Ch7에 넘긴다.

## 주의할 해석

순소요량 대신 BOM 총소요량. 재고·입고·공임·세금 등 미포함. MOQ는최소팩수. 과거판 구매조건은별도시점검색이아니므로 과거견적재현을 약속하지 않는다. 금액표시라인합계를 다시 합산하지 않는다. 모터1대차이38.69를100배하면3869.00이지만 실제100대차이는3869.10.

휠45.09는각판의기록BOM·단가차이. 이전품번팩표기불명·배수3과이후배수6을함께보여준다. 단종소요금액을손실로설명하지않는다. 모든응답이모든출처와통화필드를채우는것도아니다.

## 실행 전 검수

- 작성 과제가 미작성 상태에서 실패하고 해설은 같은 검사로 통과한다.
- CSV기준값을 확인한다.
- list/ping뿐 아니라 usage/servo 정상 호출을 확인한다.
- missing/absent/invalid-units/missing-value를 실제로 대조한다.
- 자료가 아직 원격에 게시되지 않았다면 로컬 파일로 시연하고 GitHub 게시 후 링크를 재확인한다.
