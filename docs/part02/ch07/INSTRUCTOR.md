## 시연 준비

- `ch07_plan`은 기본 규칙 해석입니다. `--llm`에서만 실제 모델을 호출합니다.
- `ch07_route`의 미작성 실패와 해설의 두 경로 통과를 확인합니다. 연습용 호출 기록과 실제 MCP 호출을 구분합니다.
- `ch07_verify`의 7개 판정과 기존 검사 테스트를 확인합니다. -13.98은 가상 검사 값입니다.
- `ch07_run`은 Neo4j와 MCP 설정이 필요합니다. 모터 15%·100대·6b2c5a9 조건의 3869.10과 비교합니다.
- 서보 되묻기와 응답은 한 프로세스에서 실행합니다. 고정 모드의 문서 검색도 임베딩 API를 사용할 수 있습니다.
- 실제 모델 재작성, 작은 검사 입력, 저장 화면 예시를 구분합니다. 관측하지 않은 실행 결과를 만들지 않습니다.

## 설명할 기준

LLM은 유형·조건을 정리하고, Python은 도구 순서를 결정하며, 도구는 계산합니다. 스킬 문서와 실제 분기를 나란히 읽습니다. 일반 조회 판은 RunContext, change_ref는 판 변경 비교 참조입니다. not_run·failed·withheld의 뜻을 나누고 자동 검사 범위를 설명합니다.

기존 서보 사진과 Lucide 아이콘을 재사용합니다. 네 단계 실행·되묻기·2개와 4개·재작성과 보류는 편집 가능한 도식입니다. 원천값·가정·기대값과 실제 관측값을 구분하세요.
