# Ch5 강사용 진행 메모

12강: Ch4 연결 1분 → 원문·청크 2.5분 → 개체 연결 1.75분 → 연결 근거 1.75분 → 오연결 과제 3분 → 색인 구성 2분 → 준비 조회 2분 → 정리 1분. 총15분.

13강: 질문 비교 1분 → BM25 2.25분 → 벡터 2.25분 → RRF 2.25분 → 문서·제품 경로 2.5분 → 조건 변경 실습 3분 → 장애 구분 1분 → Ch6 예고 0.75분. 총15분.

각 구간은 낭독과 조작을 합친 계획이며 실측이 아닙니다. 최초 임베딩 생성·패키지 설치·수강생별 추가 연습은 별도입니다.

## 시연 흐름

장표로 질문과 판단 기준 → GitHub 원문·코드·작성 표 → 터미널 또는 Neo4j 실행 → 장표로 결과 해석. 링크는 프롬프터 비낭독에서 엽니다. Ch4 load_graph를 다시 실행하지 않습니다.

오연결 과제는 작은 가상 예제이며 원문 스냅샷과 구분합니다. 수정은 학생 작업본의 LINK_OVERRIDES 한 줄만 추가합니다. 검수 이유는 별도 표에 기록합니다. 실제 DB에 없는 예제 ID를 추가해도 기존 DB 관계가 바뀌었다고 설명하지 않습니다.

## 조회 결과 대조

현재 제공 CSV 기준 Document 534개(readme240·issue288·bom_text6), SearchExample4개. 정상 의미 색인은 Voyage voyage-4 / 1024차원으로 검수했습니다. 코드·입력 버전이 달라지면 실제 출력 우선.

CQ-11의 진단 청크는 `mechanical/servo_gear_replacement/README.md#2`입니다. BM25 5위(약4.967), 벡터3위(약0.782), 결합1위(RRF약0.0313). Part 2000-0025-0002가 고장 지식을 거쳐 연결되고 최신 판 조립품은 rocker bogie입니다. 직접 연결과 curated 경유를 구분합니다. G44의 구형 SKU 1514-0010-0060은 문서가 있어도 최신 판 Assembly가 비어 있을 수 있습니다.

첫 비교에서는 source=null(기본 BOM 텍스트 제외)을 고정합니다. source=issue 등으로 바꾸면 후보와 순위 조건도 달라집니다. RRF 반올림 표시가 같아도 실제 정렬은 반올림 전 값을 사용합니다.

장애 회귀 테스트는 API·DB 없이 분기를 검사합니다. 준비된 실제 색인을 지우거나 실제 키를 망가뜨려 보여줄 필요는 없습니다.
