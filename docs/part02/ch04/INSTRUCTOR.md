## 11강 · 15분

품번·판 1분 → 직접 사용처 2분 → 제품 경로 2.5분 → 모든 판 조건 2분 → 계수·낱개 2.5분 → 직접 작성 3분 → 결과 대조 1분 → Ch5 연결 1분.

작성 과제는 60초 시연, 45초 수강생 작성, 15초 결과 대조로 배분합니다. 더 긴 실습은 영상을 멈추고 진행하도록 안내합니다.

### 템플릿 완성 예

[02-direct-usage.cypher](queries/02-direct-usage.cypher)가 완성 예입니다. 관계 방향, `l.revision_id=v.revision_id`, 판·품번·원천·팩·낱개·배수·출처 반환이 모두 있어야 합니다.

전체 제품 경로의 판 조건은 아래와 같습니다.

```cypher
WHERE all(n IN nodes(p) WHERE NOT n:BOMLine OR n.revision_id=v.revision_id)
```

개정판 선택을 포함한 전체 실행문은 [03](queries/03-product-path.cypher)을 사용합니다. CQ 파일의 `WITH v`만 붙여 실행하지 않습니다.

### 예상 관찰과 해석

- 배포 CSV 기준 Product 1, Part 103, Assembly 6, BOMLine 1265, Revision 21, ECN 16. 입력 버전·실제 결과를 함께 기록합니다.
- 최신 판 `6b2c5a9`, 휠 1경로·원천 계수 6·낱개 6, 스페이서 1경로·계수 1·낱개 4.
- `qty_each = raw_qty × pack_size`. 여기에 배수를 곱하되 팩 크기를 다시 곱하지 않습니다. 마지막 구매 팩 수·Decimal 계산은 Ch6입니다.
- 기존 모터는 최신 판 경로가 없을 수 있습니다. 노드 존재와 해당 판의 사용을 구분합니다.
- 여러 경로 합산은 07의 가상 입력만 사용합니다. 실제로 없는 복수 경로를 만들었다고 설명하지 않습니다.
- 재적재 뒤 문서 검색 성공을 시연하지 않습니다. Ch5의 `build_index.py`로 복구합니다.

학습 결과는 적재 대응표·실행 기록·작성한 조회문·조회 기록표입니다. 프롬프터 시간은 낭독 추정과 화면 확인 시간을 합산한 계획이며 실측 시간이 아닙니다.
