# 적재 확인 기록

- [ ] 접속 대상은 이 강의 전용 Neo4j이다. 업무 DB나 다른 실습의 공유 DB가 아니다.
- [ ] 앱에서 질의를 보내는 동작을 멈췄다.
- [ ] 가공 테이블과 Ch3 모델·검증 결과를 확인했다.
- [ ] 기존 그래프·임베딩·문서 연결·검색 예시가 지워지는 재적재임을 이해했다.
- [ ] 실행 폴더는 `labs/mfg-bom-agent`이다.
- [ ] `uv run python scripts/load_graph.py` 종료 코드와 입력 처리 건수를 기록했다.
- [ ] `01-load-inventory.cypher`와 `ch04_audit.py`로 실제 건수·검증을 대조했다.
- [ ] 이전·이후 모터와 개정판 연결을 확인했다.
- [ ] 검색은 아직 미구성 상태임을 기록했다. Ch5에서 `build_index.py`로 복구한다.

|기록 항목|직접 작성|
|---|---|
|실행일 / 접속 주소(암호 제외)||
|CSV 입력 행 수 / 실제 노드 건수||
|검증 검사 수 / 위반 수 / 종료 코드||
|최신 판 / 모터 변경 전후 확인||
|실패 시 마지막 완료 단계 / 재실행 결과||

여러 쿼리로 진행되므로 실패 시 전체가 자동으로 되돌아간다고 가정하지 않습니다. 원인을 확인한 후 전용 DB에서 재적재하고 다시 검사합니다. 화면에 `.env` 원문이나 비밀번호를 표시하지 않습니다.
