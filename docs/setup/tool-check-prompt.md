# 33장 · Claude Code 또는 Codex로 실습 도구 준비하기

버전이 표시되지 않거나 어떤 도구를 설치해야 할지 모르겠다면, 강의 영상을 잠시 멈추고 아래 프롬프트를 사용하세요. **실습할 컴퓨터에서** Claude Code 또는 Codex 중 하나를 열고 로컬 작업 폴더를 선택합니다. 아직 강의 저장소를 내려받지 않았다면 빈 작업 폴더로 시작해도 됩니다. 아래 블록 오른쪽 위의 복사 버튼을 누른 뒤 AI 대화 입력창에 붙여넣으세요.

```text
나는 ‘온톨로지로 만드는 엔터프라이즈 AI’ 강의의 Part 1 Ch3을 따라가는 수강생입니다. 지금 이 컴퓨터에서 33장 실습 도구를 점검하고, 빠진 도구는 설치까지 도와주세요. 기준 가이드는 https://github.com/tech-hyper-x/ontology-ai-labs/blob/main/docs/setup/README.md 의 ‘Docker와 기본 도구 설치’입니다.

1. 먼저 현재 운영체제와 터미널을 확인하세요. macOS는 Docker Desktop, Windows는 Docker Desktop과 WSL2 Ubuntu 연동, Linux는 Docker Engine과 Compose 플러그인을 기준으로 봐 주세요. 원격 환경에서 실행 중이면 내 컴퓨터에 설치됐다고 판단하지 말고 로컬에서 확인할 방법을 안내해 주세요.
2. docker --version, docker compose version, uv --version을 각각 실행해 주세요. Git으로 저장소를 받을 때는 git --version도 확인하고, ZIP으로 받는다면 Git은 선택 항목으로 표시해 주세요. 버전 명령이 실패하면 미설치인지, 현재 터미널이 실행 파일을 찾지 못하는지 구분해 주세요.
3. 버전은 다음 기준으로 판정해 주세요.
   - Docker CLI와 엔진은 저장소가 특정 버전으로 고정하지 않습니다. 엔진 실행 여부도 따로 검사하세요. Compose는 compose.yaml의 include를 쓰므로 2.20.0 이상이어야 합니다. 버전 번호는 숫자 단위로 비교하세요.
   - 제조 앱의 Python은 3.12.x입니다. PC 기본 Python 버전은 바꿀 필요가 없습니다. 저장소를 받기 전이면 ‘34장에서 확인’으로 남기세요. 패키지를 이미 준비했다면 labs/mfg-bom-agent에서 uv run --no-sync python --version으로 프로젝트 환경을 확인하세요.
   - uv는 버전 번호가 고정되어 있지 않습니다. 34장에서 제공된 uv.lock으로 패키지 준비까지 성공하면 호환을 확인할 수 있습니다. Git도 버전 고정이 없고 ZIP 사용 시 선택입니다.
   - Neo4j 5.26-community와 Langfuse 웹·워커 4는 35장에서 Compose 이미지로 실행합니다. 지금 PC에 따로 설치할 항목에서 제외해 주세요.
4. 빠졌거나 기준에 맞지 않는 도구만 운영체제에 맞는 공식 방법으로 설치하거나 업데이트해 주세요. 관리자 승인, Docker Desktop 첫 실행, 재시작처럼 내가 직접 해야 하는 동작이 있으면 화면에서 무엇을 누를지 알려 주세요. 비밀번호와 API 키는 대화에 입력하지 않습니다.
5. 설치 후 버전 명령을 다시 실행하세요. Docker는 docker info로 엔진에 연결되는지 확인한 다음 docker run --rm hello-world를 실행해 ‘Hello from Docker!’가 나오는지 확인해 주세요. 엔진이 꺼져 있거나 이미지 다운로드가 실패하면 원인을 구분해서 알려 주세요.
6. 도구별로 ‘기준 | 내 버전 | 확인 결과 | 다음 행동’을 표로 정리해 주세요. 33장에서 확인한 항목과 34·35장에서 확인할 항목을 구분하세요. 직접 확인하지 못한 항목은 ‘미확인’으로 적어 주세요. 여기서는 도구 준비까지만 하고 강의 프로젝트의 서비스 실행과 데이터 적재는 이후 장표에서 진행합니다.
```

결과에서 **Compose 2.20.0 이상**, **uv 실행 여부**과 **Hello from Docker!**를 확인하면 33장의 **GitHub 프로젝트 다운로드**로 이어가세요. 설치 위치와 운영체제별 화면은 [강의 설치 가이드](README.md#2-docker와-기본-도구-설치)에서 확인할 수 있습니다.
