# 장표별 Hands-on 실습 목차

장표 번호로 실행 안내와 코드를 찾습니다. 각 안내에서 **실행 위치 → 코드 실행 → 결과 확인** 순서로 진행합니다.

- 처음 시작한다면 [공통 설치 안내](../setup/README.md)와 [Ch3 실행 안내](../ch03-run-guide.md)를 완료합니다.
- Cypher가 처음이라면 [Neo4j 기본 문법](../neo4j-cypher-basics.md)을 먼저 확인합니다.
- **[32장 · 휠 사용처 조회를 처음부터 따라 하기](../part01/ch03/slide-032.md)**: 입력 조건·표 조회·그래프 조회를 하나씩 실행합니다.
- Neo4j Browser의 `:params`와 `MATCH` 조회문은 **따로 실행**합니다. 코드 블록의 복사 버튼을 이용하세요.
- 코드·설정 원문을 읽는 단계와 실제 명령을 실행하는 단계는 구분합니다. Python 소스 전체를 터미널에 붙여 넣지 않습니다.
- Part 3 조회는 준비된 바이오 DB·검색 색인을 전제로 합니다. 제조 DB로 실행하지 않습니다. [바이오 준비 상태](../../examples/part03/README.md)를 먼저 확인하세요. 공개 예제만으로 바이오 전체 실행 환경이 설치되지는 않습니다.
- 현재 작성된 강의의 실습 코드가 있는 **88개 장표**를 연결합니다. 설치·계산·검색·모델 호출은 각 단계의 준비 조건을 먼저 확인하세요. 모든 코드를 자동 실행하는 목록은 아닙니다.
