강의에서 제공한 바이오 프로젝트와 고정 DB·색인을 준비한 뒤 실행합니다. 현재 공개 저장소에는 바이오 전체 실행 환경·데이터가 아직 포함되어 있지 않습니다. 이 폴더의 조회문은 DB·색인을 생성하지 않으며, 저장 임베딩을 사용하는 조회는 새 임베딩 API를 호출하지 않습니다.

Neo4j Browser에서 `:params`와 Cypher를 각각 실행합니다. 제조 DB와 바이오 DB의 접속 주소를 구분합니다.
